## セレニウムでスクレイピングをするメリット

Seleniumはブラウザの動作をシミュレートできるため、人間のようなアクセスとして見逃されにくいのが最大の強みです。従来のcurlコマンドやrequestsライブラリでは検知されやすいですが、Seleniumを使うとWebサイト管理者から隠蔽できます。また、複数のブラウザウィンドウを同時に操作できるので、大規模なデータ収集にも対応します。

## 準備するもの

- Chrome ブラウザ
- Selenium WebDriver（PythonまたはJavaScript）
- Node.js環境（JavaScript版の場合）
- パスワードマネージャー（プロキシ認証用）
- ロボット検知回避用のユーザーエージェントリスト

## セットアップ手順

1. Pythonなら、pip install seleniumでインストール
2. Chromeを起動し、chrome://extensions/から「Chrome DevTools Protocol」を有効化
3. WebDriver Managerをインストールして、Seleniumが自動的にブラウザを制御できるようにする

```python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

options = Options()
options.add_argument('--headless')  # ヘッドレスモードで高速処理可能
driver = webdriver.Chrome(options=options)
```

## 実際のスクレイピングスクリプト例

Amazonの製品情報を収集する場合：

```python

for item in driver.find_elements(By.CSS_SELECTOR, ".product-item"):
```

## IPバンの回避方法

Seleniumでスクレイピングすると、IPアドレスがブロックされるのが頻繁です。対策：

- **プロキシローテリング**: 複数のプロキシを回転させながらアクセス
- **レスパイトバックオフ**: アクセス間隔を適宜空ける
- **ブラウザフィンガープリンティング回避**: User-AgentやCookieを無作為に切り替える

無料プロキシサービス（Bright Data、Scholarlyなど）を使えば、数千のIPアドレスから選択できます。ただし、高品質なWebサイトほど検知されるので、注意が必要です。

## FAQ

**Q: SeleniumとBeautifulSoupどちらがいい？**
A: BeautifulSoupは軽量で高速ですが、JavaScript依存サイトの対応が苦手です。Seleniumは重いが、あらゆるWebサイトに対応します。

**Q: PythonとJavaScriptのどちらを使うべき？**
A: 初心者ならPython。ライブラリが豊富で可読性が高い。大規模システムならJavaScript（Puppeteerなど）の方が適しています。

**Q: 刑罰的なリスクはある？**
A: デジタル著作権法違反や不正アクセス処置条例違反の可能性があります。個人利用でも検挙例があります。
