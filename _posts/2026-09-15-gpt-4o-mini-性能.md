GPT-4o mini は、OpenAI が2024年7月に公開した「安くて速い」軽量モデルです。API の料金が非常に安かったため、チャットボットや文章の分類・要約など、たくさんの処理をこなすアプリで広く使われてきました。

ただし2026年10月、OpenAI は **GPT-4o mini を API から外す予定**を発表しました。この記事では、まず結論と終了日程を確認し、発表時の性能をおさらいしたうえで、移行先の選び方と移行前のチェック項目をまとめます。

## 結論：2027年1月14日までに移行先を決める

- OpenAI の API での **GPT-4o mini（`gpt-4o-mini-2024-07-18`）の提供終了日は2027年1月14日**の予定です。GPT-4o・GPT-4.1・GPT-4.1 mini も同じ日に終了します（[OpenAI の Deprecations ページ](https://developers.openai.com/api/docs/deprecations)、[DataNorth の解説](https://datanorth.ai/news/gpt-4o-and-gpt-4-1-leave-openais-api-on-14-january-2027-fine-tuned-versions-included)）。
- 推奨の移行先として挙げられているのは **`gpt-6-luna`** です。料金は GPT-4o mini より安い水準と報じられていますが、**推論（reasoning）モデル**なので、モデル名を書き換えるだけでは動きが変わる場合があります。
- GPT-4o mini を**ファインチューニング**したモデルも、元のモデルと同じ日に使えなくなります。
- Microsoft の Azure OpenAI は**別の日程**です。Azure で使っている場合は [Azure のモデル廃止ページ](https://learn.microsoft.com/en-us/azure/ai-services/openai/concepts/model-retirements)を確認してください。

なお、ChatGPT（アプリ・Web）では GPT-4o mini はすでに新しいモデルに置き換わっていて、選ぶことはできません。この記事の話は、**API で GPT-4o mini を呼び出しているアプリ**が対象です。

## GPT-4o mini とは：発表時の性能と料金

まずは、GPT-4o mini がどんなモデルだったかをおさらいします。数値は OpenAI の発表（[GPT-4o mini: advancing cost-efficient intelligence](https://openai.com/index/gpt-4o-mini-advancing-cost-efficient-intelligence/)、2024年7月18日）によるもので、OpenAI 自身の測定です。

| 項目 | 内容 |
|---|---|
| 公開日 | 2024年7月18日 |
| 入力 | テキストと画像（出力はテキスト） |
| コンテキスト長 | 12万8,000トークン（出力は最大1万6,000トークン） |
| 知識の範囲 | 2023年10月まで |
| 料金（API） | 入力 100万トークンあたり **0.15ドル**、出力 **0.60ドル** |
| MMLU（知識・推論） | 82.0%（同時期の Gemini Flash 77.9%、Claude Haiku 73.8%） |
| MGSM（数学） | 87.0% |
| HumanEval（コード） | 87.2% |

発表時の売りは「GPT-3.5 Turbo より60%以上安く、性能は上」という点でした。ChatGPT でも、無料版などで GPT-3.5 に代わって使われるようになりました。

### 誤解されやすい点

ネット上には GPT-4o mini について誤った情報も見られます。よくある誤解を整理しておきます。

- **オープンソースではありません。** 重み（モデル本体）は公開されておらず、OpenAI の API か ChatGPT 経由でしか使えません。手元のPCで動かしたい場合は、Qwen や Gemma などの公開モデルを使います（[Ollamaのインストール方法]({% post_url 2026-09-26-ollama-インストール-方法 %})）。
- **API に毎月の無料枠はありません。** API は使った分だけ支払う従量課金です。
- **GPT-4o と同じ性能ではありません。** 軽量版なので、難しい推論や長い文章の正確さでは上位モデルに劣ります。発表時の比較対象は、同じ軽量クラスの Gemini Flash や Claude Haiku でした。

## 2026年の位置づけ：もう「最安・最新」ではない

2024年当時は破格だった GPT-4o mini ですが、2026年11月時点では、より新しい軽量モデルが同じかそれ以下の料金で出ています。主な OpenAI の軽量モデルの料金（100万トークンあたり）は次のとおりです。

| モデル | 入力 | 出力 | メモ |
|---|---|---|---|
| gpt-4o-mini | 0.15ドル | 0.60ドル | 2027年1月14日に終了予定 |
| gpt-5-nano | 0.05ドル | 0.40ドル | 推論モデル。最安クラス |
| gpt-5-mini | 0.25ドル | 2.00ドル | 推論モデル |
| gpt-6-luna | 0.10ドル | 0.50ドル | 推奨の移行先。2026年9月公開と報道 |

出典: [OpenAI の料金ページ](https://developers.openai.com/api/docs/pricing)、gpt-6-luna は料金比較サイト（[Developers Digest](https://www.developersdigest.tech/models/gpt-6-luna) など）の掲載値。料金は変わることが多いので、使う前に必ず公式の料金ページで確認してください。

表の上では gpt-6-luna のほうが安く見えますが、**推論モデルは答える前に「考える」ためのトークン（推論トークン）を使い、その分も出力として課金されます**。同じ質問でも出力トークンが増えることがあるため、1回あたりの実際の費用は、自分の使い方で測ってみないとわかりません。

## 移行先の選び方

移行先は「何に使っているか」で決めるのが現実的です。

| 今の使い方 | 候補 | 選ぶときのポイント |
|---|---|---|
| 分類・タグ付け・短い要約など大量の定型処理 | gpt-6-luna / gpt-5-nano | 料金が最も効く用途。推論の強さ（reasoning effort）を低めにできるか確認 |
| チャットボット・問い合わせ対応 | gpt-6-luna / gpt-5-mini | 応答までの時間（待ち時間）を必ず測る |
| 関数呼び出し（ツール）を使うエージェント | gpt-6-luna など | ツール呼び出しの挙動が変わると報じられている。テストを厚めに |
| 画像を読み取る処理 | 画像入力に対応したモデル | 対応しているかをモデルのページで確認 |
| 社外に出せないデータを扱う | ローカルLLM | [Qwen 2.5 の日本語性能]({% post_url 2026-09-27-qwen-25-日本語-性能 %}) なども参考に |

OpenAI 以外に乗り換える選択肢もあります。Google の Gemini（Flash 系）や Anthropic の Claude（Haiku 系）にも軽量モデルがあり、それぞれの特徴は [Claude・ChatGPT・Geminiの違いと使い分け]({% post_url 2026-10-08-claude-ai-比較 %}) で整理しています。ただし、サービスを変えると SDK や料金体系、データの取り扱いの規約も変わるので、移行の手間は大きくなります。

## 移行前のチェックリスト

モデル名を書き換える前に、次の点を確認しておくと安全です。

1. **どこで GPT-4o mini を使っているか洗い出す。** コード内の `gpt-4o-mini` という文字列だけでなく、設定ファイル・環境変数・ノーコードツール（n8n など）の設定も探します。
2. **日付つきの名前に注意する。** `gpt-4o-mini-2024-07-18` のように日付で固定している場合も終了の対象です。
3. **ファインチューニング済みモデルの有無を確認する。** 同じ日に使えなくなるため、新しいモデルで作り直すか、プロンプトの工夫で代わりになるかを検討します。
4. **パラメータが通るか確かめる。** 推論モデルでは、`temperature` など一部のパラメータが使えない、または意味が変わることがあります。エラーにならないか、テスト環境で一度呼び出してください。
5. **出力の形式を確認する。** JSON で受け取っている場合は、形式が崩れないか（Structured Outputs を使うと安定しやすい）を確認します。
6. **費用と待ち時間を測る。** 推論トークンの分、費用と待ち時間が変わります。次の節のスクリプトで、いつものプロンプトを使って比べるのがおすすめです。
7. **期限の前に切り替える。** 終了日の直前は問い合わせが混みます。余裕を持って12月中に切り替えるのが無難です。

## 同じプロンプトで新旧モデルを比べるスクリプト

いつも使っているプロンプトを複数のモデルに投げ、応答時間・トークン数・概算の費用を CSV に書き出す Python スクリプトです。`openai` パッケージ（このスクリプトは 3.59.0 で確認）を使います。

```python
"""同じプロンプトを複数のモデルに投げ、応答時間・トークン数・概算コストを比べる"""
import csv
import time

from openai import OpenAI

# 料金は 100万トークンあたりのドル（入力, 出力）。必ず公式の料金ページで最新値に直してから使う
PRICES = {
    "gpt-4o-mini": (0.15, 0.60),
    "gpt-6-luna": (0.10, 0.50),
}
PROMPTS = [
    "次の文を30字以内で要約してください: 本日の会議では、来期の予算配分と新製品の発売時期について議論した。",
    "次のレビューは「肯定」「否定」「中立」のどれ？ 1語で答えて: 届くのが遅かったが、品質は値段以上だった。",
]

client = OpenAI()  # APIキーは環境変数 OPENAI_API_KEY から読む

with open("result.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["model", "prompt_no", "seconds", "input_tokens", "output_tokens", "usd", "answer"])
    for model, (p_in, p_out) in PRICES.items():
        for i, prompt in enumerate(PROMPTS, 1):
            start = time.perf_counter()
            res = client.chat.completions.create(
                model=model,
                messages=[{"role": "user", "content": prompt}],
            )
            sec = time.perf_counter() - start
            u = res.usage
            usd = (u.prompt_tokens * p_in + u.completion_tokens * p_out) / 1_000_000
            answer = res.choices[0].message.content.strip()
            writer.writerow([model, i, f"{sec:.2f}", u.prompt_tokens, u.completion_tokens, f"{usd:.6f}", answer])
            print(f"{model} #{i}: {sec:.2f}秒 ${usd:.6f} → {answer[:40]}")
```

使い方:

```bash
pip install openai
export OPENAI_API_KEY="あなたのAPIキー"   # Windows の PowerShell なら $env:OPENAI_API_KEY="..."
python compare_models.py
```

`PROMPTS` を実際の業務で使っている文章に差し替えると、移行後の品質と費用の見当がつきます。推論モデルの `completion_tokens` には推論トークンも含まれるので、費用の比較にそのまま使えます。

> **動作確認について:** このスクリプトは、OpenAI 互換の応答を返す模擬サーバーを相手に実行し、CSV が正しく出力されることを確認しました。実際の OpenAI API での実行と、gpt-6-luna の応答内容は**未検証**です。

プロンプトそのものを見直すと、軽いモデルでも結果が安定しやすくなります。書き方の基本は [プロンプトエンジニアリング入門]({% post_url 2026-09-27-プロンプトエンジニアリング-入門 %}) を参考にしてください。

## よくある質問

**Q. 2027年1月14日を過ぎると、どうなる？**
A. `gpt-4o-mini` を指定した API の呼び出しがエラーになります。アプリがそのモデルに頼っている場合は止まってしまうので、早めの切り替えが必要です。

**Q. モデル名を変えるだけで済む？**
A. 簡単な使い方なら済むこともありますが、推論モデルでは使えるパラメータやツール呼び出しの挙動が違う場合があります。テスト環境で一度動かしてから本番を切り替えてください。

**Q. GPT-4o mini をこれから新しく使い始めてもいい？**
A. おすすめしません。数か月で使えなくなるため、新しく作るアプリは最初から後継モデルで作るほうが二度手間になりません。

**Q. ChatGPT の無料版にも影響はある？**
A. ChatGPT ではすでに新しいモデルに切り替わっているため、今回の API の終了で使い方が変わることはありません。

## まとめ

- GPT-4o mini は2024年7月公開の軽量モデル。**入力0.15ドル・出力0.60ドル（100万トークンあたり）**の安さで広く使われた
- OpenAI の API では **2027年1月14日に提供終了**の予定。GPT-4o・GPT-4.1・GPT-4.1 mini も同日
- 推奨の移行先は **gpt-6-luna**。ただし推論モデルなので、パラメータ・ツール呼び出し・推論トークンの費用を事前に確認する
- **自分のプロンプトで新旧を比べてから**切り替え、終了日の直前は避ける

*情報は2026年11月25日時点のものです。終了日程・推奨の移行先・料金は変更されることがあります。必ず OpenAI の Deprecations ページと料金ページで最新情報を確認してください。*
