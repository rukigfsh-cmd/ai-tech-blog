## [Ollama](https://ollama.ai) のダウンロードとインストール

Ollama を使用する前に、公式サイトから最新のバイナリファイルをダウンロードしてください。

**公式サイトのアクセス方法：**
https://ollama.com/download

Macユーザーの場合：
- ダウンロードした.dmg ファイルを開く
- アプリをダブルクリックして起動
- セキュリティ警告が出ても「開き」を選択

Windows の場合：
- ダウンロードしたexe ファイルを実行
- Windows Defender がブロックする場合は、一時的にアンチウイルスを無効化するか、Ollama を信頼済みアプリとして追加

## 初期設定とモデルの読み込み

起動後、以下のコマンドライン操作でモデルを読み込みます。

```bash
ollama run llama3.2
```

これはLlama3.2というオープンソースLLMを実行する例です。最初にダウンロードされるため、数百MBのデータを消費します。

## ローカル環境での使用手順

Ollama をローカルで動作させると、以下の利点があります：

**完全なプライバシー：** データがサーバーに送信されない
**オフライン利用：** インターネット接続不要でLLMを使用可能
**高速応答：** ローカルGPU の場合、秒単位で回答生成

モデルを操作するには以下コマンドがあります：

```bash
# 新しいチャットを開始
ollama run llama3.2

# 会話に追加する
OLLAMA: こんにちは
ユーザー：こんにちは、天気はどうですか？

# モデルを終了
ctrl+c または exit コマンド
```

## GPU アクセラレーションの設定

高速な推論速度を得るには、GPU を有効にする必要があります。

Mac の場合：
Ollama はApple Silicon (M1/M2/M3/M4) を自動的に利用します。Intel Mac だとCPUのみで動作しますが、非常に遅くなります。

Windows の場合：
- NVIDIA GPU ：CUDAツールキットをインストールし、ollama で`--gpu`フラグを追加
- AMD GPU ：ROCmスタックが必要（Ollama は現在AMD 完全対応ではない）

例：
```bash
ollama run llama3.2 --model-family mamba
```

## トラブルシューティング

**「モデルをダウンロードできません」：** ファイアウォールのブロックが原因。セキュリティソフトを一時的に無効化して再試行してください。

**「GPU が認識されない」：** Windows の場合、CUDAバージョンがOllama と不整合している可能性があります。公式サイトで推奨バージョンを確認してください。

**「応答が遅い」：** モデルサイズが大きすぎるか、CPU みの動作が原因です。可能な限り7B以下のモデルを使用し、Mac の場合はApple Silicon に切り替えてください。
