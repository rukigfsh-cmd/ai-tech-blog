近年、大規模言語モデル（LLM）の活用方法が急速に進化しています。その中で「プロンプトエンジニアリング」という技術が注目されていますが、具体的に何をすればいいのでしょうか？本記事では、初心者でも実践できる5つの基本テクニックを解説します。

## プロンプトエンジニアリングとは？

プロンプトエンジニアリングとは、LLMの出力品質を意図的に向上させるための手法の総称です。単に「良い質問をする」だけでなく、モデルの内部構造や学習特性を利用した高度な最適化技術を含みます。

なぜこれらのテクニックが必要なのか？それは、LLMは「確率的推論」によって動作しているため、同じクエリでも出力がばらけるからです。プロンプトエンジニアリングは、そのバラつきを最小限に抑えつつ、目的の回答を引き出すための技術です。

## テクニック1: few-shot prompting（少サンプル提示）

LLMには「学習」機能がありませんが、「文脈」として情報を渡すことで、一時的に能力を向上させます。

例：
```
以下の形式で住所を変換してください：
東京都渋谷区桜丘町2-1 → 206-0834
東京都新宿区西新宿3-5-1 → 

東京都港区六本木9-10-1 → 
```

このように「入力→出力」のペアを数個提示することで、モデルはパターンを学習し、未知の入力に対しても高い精度で処理します。GPT-4では3〜5サンプルが有効で、GPT-3.5ではさらに多く必要です。

## テクニック2: chain-of-thought（思考連鎖）

複雑なタスクに対して、LLMに「段階的に考える」ように指示を与えます。これはChain-of-Thought推論と呼ばれ、数学問題や論理的思考において特に有効です。

例：
```
以下の計算問題を解いてください。途中の考え過程も明記してください：
17 + 23 × 0.5 = ?
```

モデルは「まず掛け算を実行 → 次に足算」のように、人間に近い思考プロセスを再現します。これにより、単純な誤り検知が可能になります。

## テクニック3: temperature制御

LLMには「temperature」というパラメータがあり、0〜1の範囲で調整できます。
- temperature=0：ほぼ決定論的。同じ入力でも毎回同じ出力
- temperature=0.7：創造性が高まるがバラつきも増える

タスクによって最適温度が変わります。事実確認なら低め、創作系なら高めに設定するのが基本です。OpenAIのAPIではtemperature引数で指定可能ですが、UI版では「Sampling」セクションから調整できます。

## テクニック4: role-playing（ロールプレイ）

LLMに特定の役割を与えることで、出力のトーン＆マナーや専門性を制御できます。

例：
```
あなたは経験豊富なITコンサルタントです。以下の問題に対するアドバイスを3段階で提示してください。
```

「専門家」というフックは、モデルがより確信的な回答を生成するようになり、事実誤認を含む回答も出やすくなります（Hallucination）。ただし、構造的なアドバイスが必要な場合、非常に有効です。

## テクニック5: recursive refinement（反復改善）

一度出力してもらった後、それを再度入力して修正を要求します。
```
上記の回答をより具体的で実用的なものに書き換えてください。数値例も3つ追加してください。
```

この手法は「人間が編集する」ことと同等の効果があります。ただし、API経由で自動化できるため、バッチ処理において特に強力です。

## 応用例と注意点

これらの技術は、以下のような用途で使われています：
- SEO：検索意図に合わせた自動記事生成
- コード：バグ修正や最適化の効率化
- データ分析：複雑な統計データの可視化
- 翻訳：文脈を考慮した高精度翻訳

ただし注意点もあります。プロンプトエンジニアリングに依存しすぎると、モデルの依存度が高まり、本来なら人間がやるべき作業まで代行されるリスクがあります。また、黒い市場でLLM APIを不正利用するケースも増加しています。

## FAQ（よくある質問）

**Q1: プロンプトエンジニアリングは違法ですか？**
A: 技術的には合法ですが、API利用規約違反や著作権侵害に巻き込まれる場合は法的責任が問われます。特に画像生成モデルの商用利用制限は厳格です。

**Q2: どのLLMにプロンプトエンジニアリングは有効ですか？**
A: GPT-4 Turbo、[Claude](https://claude.ai) 3.5 Sonnet、[Gemini](https://gemini.google.com) Advancedなど、トップクラスのモデルほど効果的です。安価なモデルでは効果が限定的です。

**Q3: 学習曲率はどれくらいか？**
A: 基本テクニック（few-shot、role-playing）は1週間程度で習得可能。chain-of-thoughtやrecursive refinementは実践を通じて上達します。公式ドキュメントの「Advanced Prompting」セクションを参照するのが効率的です。
