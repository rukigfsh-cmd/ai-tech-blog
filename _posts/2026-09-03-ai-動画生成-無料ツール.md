「AIで動画を作ってみたいけれど、まずは無料で試したい」という人向けに、2026年11月時点で無料で使えるAI動画生成の実情をまとめました。

先に結論を書きます。

- **2026年に状況が大きく変わった**: OpenAI の Sora はアプリとWeb版が2026年4月26日に終了しました。Google の Gemini アプリの動画生成は、無料プランでは使えません（有料プランのみ）。
- **無料で試せるのは「短く・透かし入り・商用不可」が基本**: Kling AI などに無料枠はありますが、多くは数秒の動画・透かし入りで、商用利用は有料プランが前提です。
- **無料のまま長く使うならローカル**: Wan 2.2 などのオープンなモデルを自分のPCで動かせば、利用料はかかりません。ただし GPU（VRAM 12GB以上が目安）と時間が必要です。

この記事は 2026年11月26日に確認した情報です。各サービスの無料枠は数か月単位で変わるため、使う前に必ず公式の料金ページを確認してください。編集部では各サービスの動画生成を実際には試しておらず、数値は公式発表や報道・各社の解説記事にもとづきます。

## 2026年に何が変わったか

### Sora は終了（アプリ・Web版は2026年4月26日）

OpenAI の動画生成アプリ「Sora」は、2026年3月に終了が発表され、**2026年4月26日にアプリとWeb版の提供を終えました**。OpenAI のヘルプによると、API はそれより後の2026年9月24日に終了する予定とされていました（[OpenAI ヘルプ: Sora の提供終了について](https://help.openai.com/en/articles/20001152-what-to-know-about-the-sora-discontinuation)、[CBS News](https://www.cbsnews.com/news/sora-ai-openai-discontinues/)、[Axios](https://www.axios.com/2026/03/24/openai-discontinue-sora-video-app)）。

「Sora を無料で使う方法」を紹介する記事はまだ多く残っていますが、今は使えません。

### Gemini の動画生成は Veo から「Gemini Omni」へ。無料版は対象外

Google は2026年5月の Google I/O で、新しい動画生成モデル「Gemini Omni」を発表しました。Gemini アプリの動画生成は Veo 3.1 から Omni に置き換わり、会話しながら動画を直せるのが特徴です（[SHIFT AI TIMES](https://shift-ai.co.jp/blog/58610/)、[AI Revolution](https://ai-revolution.co.jp/media/what-is-gemini-omni/)）。

使えるのは Google AI Plus・Pro・Ultra などの**有料プランの18歳以上のユーザー**で、無料プランでは使えません。2026年7〜8月には、未加入のユーザーが最大10本まで無料で作れる期間限定のキャンペーンがありましたが、すでに終わっています（[PC Watch](https://pc.watch.impress.co.jp/docs/news/2129264.html)）。1日に作れる本数は、プランや時期によって記事ごとに書かれている数字が違うため、ここでは断定しません。

Gemini のプラン全体の違いは「[Geminiの特徴と使い方：無料版でできることと有料プランの違い]({% post_url 2026-10-02-gemini-google-ai-特徴 %})」にまとめています。

## 無料で試せる主なサービス（2026年11月時点）

「無料」といっても、**毎日もらえるクレジット**なのか、**最初に1回だけもらえるお試し分**なのかで、使える量がまったく違います。代表的なサービスを、わかっている範囲で整理しました。

| サービス | 無料枠のタイプ | 無料で作った動画の扱い | 備考 |
|---|---|---|---|
| Kling AI | 毎日のクレジット（66クレジット/日とする記事が多い） | 透かしあり・商用不可 | 付与量はアカウントや時期で変わるという報告あり |
| Runway | 最初に1回だけ（125クレジット） | 透かしあり | Gen-4.5 は1秒あたり12クレジット＝約10秒分 |
| Hailuo AI（MiniMax） | 登録時のお試しクレジット（有効期限が短い） | 透かしあり・商用は有料プランのみ | 毎日のボーナスの有無は記事によって違う |
| Adobe Firefly | 無料プランで動画生成を回数限定で試せる | 商用利用の条件は公式で確認 | Adobe ID が必要 |
| Gemini（Gemini Omni） | 無料プランでは使えない | ― | 有料プラン（Google AI Plus 以上） |
| Sora | 終了 | ― | 2026年4月26日に提供終了 |

出典: Kling は [Marc Andrews の検証記事](https://marcandrews.com/kling-ai-free-plan-2026-what-66-credits-buys/)・[eesel AI](https://eesel.ai/blog/kling-ai-pricing)、Runway は [Dreamina（CapCut）の比較記事](https://dreamina.capcut.com/ai-video/free-ai-video-generators-recurring-credits-vs-trials-2026)・[Scrimba](https://scrimba.com/articles/free-ai-video-generators-2026/)、Hailuo は [Costbench](https://costbench.com/software/ai-video-generators/hailuo-ai/free-plan/)・[WaveSpeed](https://wavespeed.ai/blog/cost-and-billing/hailuo-ai-pricing-2026/)、Adobe Firefly は [Adobe ヘルプ](https://helpx.adobe.com/jp/firefly/using/firefly-generation-credits-for-third-party-models-jp.html)・[miralab](https://miralab.co.jp/media/adobe_firefly_videomodel/)。いずれも2026年の記事で、公式の料金ページの数字とずれている可能性があります。

### 無料枠でどれくらい作れるか

無料枠で作れるのは、だいたい**5〜10秒のクリップを数本**です。たとえば Runway の無料分（125クレジット）は、Gen-4.5（1秒12クレジット）なら約10秒ぶんで使い切ります。

「1分の動画を無料で丸ごと作る」のは、今の無料枠では現実的ではありません。無料枠は、**どのサービスの絵作りが自分の用途に合うかを見比べるため**に使うのがおすすめです。

### 「テキストから映像」と「アバター・テンプレート型」は別物

AI動画のツールには、大きく2つの種類があります。

1. **映像生成型**（Kling・Runway・Hailuo・Gemini Omni など）: 文章や画像から、新しい映像そのものを作る。数秒の印象的なカットが得意。
2. **アバター・テンプレート型**（HeyGen・D-ID・InVideo・Pictory・Fliki など）: 台本から、話すアバターや素材映像＋ナレーションの「説明動画」を組み立てる。解説動画や社内向けの動画が得意。

「YouTube の解説動画を作りたい」なら2の方が向いていて、「SNS で目を引く数秒の映像がほしい」なら1が向いています。2のタイプも多くは無料プランかお試しがありますが、無料で書き出せる長さ・透かし・商用利用の条件はサービスごとに違い、よく変わるため、使う前に各社の料金ページで確認してください。

## 無料枠を使うときの注意点

### 透かし（ウォーターマーク）を消して使わない

無料プランで作った動画には、ほとんどの場合サービスのロゴ（透かし）が入ります。**透かしを消すツールで消して使うのは、多くのサービスの規約違反**になるので避けてください。透かしなしで使いたいなら、有料プランにするか、透かしの入らないローカル生成を選びます。

### 商用利用は「無料プランは不可」が基本

Kling や Hailuo では、無料プランで作った動画は商用利用できず、商用で使えるのは有料プランからとされています（出典は上の表を参照）。収益化した YouTube チャンネルや広告、販売する商品に使うなら、**有料プランの規約で商用利用が認められているか**を必ず確認してください。

### 人物・キャラクター・ブランドの扱い

- 実在の人物の顔や声に似せた動画は、肖像権やパブリシティ権の問題になりえます。
- アニメや映画のキャラクター、他社のロゴに似せた動画は、著作権・商標権の問題になりえます。
- AI生成物と著作権の考え方は、文化庁の「[AIと著作権について](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html)」がまとまっています。

AIで作った画像や動画を販売する場合のルールは、「[AI画像の販売方法：販売先ごとの規約と始め方・注意点]({% post_url 2026-09-07-ai画像-販売-方法 %})」も参考にしてください。

### 入力した画像・文章の扱い

自分の写真や社内の資料を入れる場合は、そのデータが学習に使われるか・どこに保存されるかを、各サービスのプライバシーポリシーで確認しましょう。気になるなら、次のローカル生成が安心です。

## 無料のまま使い続けるなら「ローカル生成」

自分のPCで動画生成モデルを動かせば、クレジットも透かしもありません。代表的なのは次の2つです。

- **Wan 2.2**（Alibaba）: 2025年7月公開。Apache 2.0 ライセンスで、商用利用も含めて無料で使えるとされています。ASCII の検証では、RTX 4070（VRAM 12GB）で 5B モデルは動いたものの、メモリのやりくりが必要で生成に時間がかかり、14B モデルは12GBでは現実的でなかったと報告されています（[週刊アスキー](https://weekly.ascii.jp/elem/000/004/316/4316324/)）。
- **LTX-2 / LTX-2.3**（Lightricks）: NVIDIA の案内では、RTX 5090（32GB）で720p・4秒のクリップを約25秒で作れる一方、VRAM を多く使います（[NVIDIA: Quick Start Guide For LTX-2 In ComfyUI](https://www.nvidia.com/en-gb/geforce/news/rtx-ai-video-generation-guide)）。12GB の GPU でも解像度を抑えれば試作できたという報告があります（[週刊アスキー](https://weekly.ascii.jp/elem/000/004/387/4387092/2/)）。ライセンス条件はモデルごとに公式で確認してください。

どちらも ComfyUI（ノードをつないで画像・動画を作る無料ソフト）から使うのが一般的です。VRAM が足りないときの対策は「[VRAM不足を解決する方法]({% post_url 2026-10-12-vram-不足-解決-方法 %})」で、ノートPCで GPU を足す方法は「[外付けGPU（eGPU）の始め方]({% post_url 2026-10-13-外付けgpu-egpu-接続 %})」で解説しています。

| | クラウドの無料枠 | ローカル生成 |
|---|---|---|
| 費用 | 0円（量はわずか） | 0円（電気代のみ。GPU は必要） |
| 透かし | ほぼ入る | 入らない |
| 商用利用 | 無料プランは不可が多い | モデルのライセンス次第（Wan 2.2 は Apache 2.0） |
| 画質・手軽さ | 高画質・ブラウザだけで使える | 設定が必要。高画質ほど高性能な GPU が必要 |

## 短いクリップをつないで1本の動画にする（ffmpeg）

無料枠やローカル生成で作れるのは数秒のクリップです。何本か作ったら、無料の動画変換ソフト **ffmpeg** で1本にまとめられます。以下のコマンドは、編集部が ffmpeg 6.1 でテスト用の映像を使って実行し、動くことを確認しました（Windows でも Mac でも同じコマンドです）。

### 1. 解像度と形式をそろえる

サービスごとに解像度やフレームレートが違うと、そのままではつなげません。まず、すべて 1280×720・24fps にそろえます。

```bash
# 音声つきのクリップ
ffmpeg -i clip1.mp4 -vf "scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2,fps=24,format=yuv420p" -c:v libx264 -crf 20 -c:a aac -ar 48000 -ac 2 01.mp4

# 音声のないクリップ（無音の音声を足してそろえる）
ffmpeg -i clip2.mp4 -f lavfi -i anullsrc=r=48000:cl=stereo -vf "scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2,fps=24,format=yuv420p" -c:v libx264 -crf 20 -c:a aac -shortest 02.mp4
```

### 2. つなぐ

つなぐ順にファイル名を書いた `list.txt` を作ります。

```text
file '01.mp4'
file '02.mp4'
```

```bash
ffmpeg -f concat -safe 0 -i list.txt -c copy joined.mp4
```

### 3. 字幕・フェード・縦長への変換

```bash
# 字幕（SRTファイル）を焼き込む
ffmpeg -i joined.mp4 -vf "subtitles=sub.srt" -c:a copy subbed.mp4

# 最初と最後にフェード（15秒の動画の例。st は開始秒）
ffmpeg -i joined.mp4 -vf "fade=t=in:st=0:d=1,fade=t=out:st=14:d=1" -af "afade=t=in:st=0:d=1,afade=t=out:st=14:d=1" faded.mp4

# 横長をショート動画向けの縦長（1080×1920）に。背景はぼかした同じ映像
ffmpeg -i joined.mp4 -filter_complex "[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,boxblur=20:2[bg];[0:v]scale=1080:-2[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2" -c:v libx264 -crf 23 -c:a copy vertical.mp4
```

日本語の字幕は、PCに日本語フォントが入っていれば表示されます。

## 品質を上げるプロンプトのコツ

- **1カット1動作**: 「猫が窓から飛び降りて、走って、振り返る」より「黒猫が窓辺から床へ飛び降りる」のように、1回の生成では動きを1つに絞る。
- **カメラの動きを書く**: 「ゆっくりズームイン」「横に流れるように追う」など。指定しないとカメラが不自然に揺れることがある。
- **最初の1枚を画像で渡す**: 多くのサービスは「画像から動画」に対応しています。先に画像生成AIで構図を決めてから動かすと、狙いに近づきやすい。
- **人の手・文字は崩れやすい**: 手のアップや看板の文字は避け、文字は後から字幕で入れる。

プロンプトの基本的な考え方は「[プロンプトエンジニアリング入門]({% post_url 2026-09-27-プロンプトエンジニアリング-入門 %})」も参考にしてください。

## よくある質問

**Q. 完全無料で、透かしなし・商用利用OKのクラウドサービスはある？**

A. 2026年11月時点で、主要なサービスにはほぼありません。透かしなし・商用利用を無料で両立したいなら、ライセンスが商用利用を認めているモデル（例: Wan 2.2）をローカルで動かすのが現実的です。

**Q. Sora の代わりは？**

A. 映像の質で選ぶなら、Gemini Omni（Google AI Plus 以上）や Kling・Runway の有料プランが候補です。まず各サービスの無料枠で同じプロンプトを試し、気に入ったものだけ有料にするのがおすすめです。

**Q. AI で作った動画を YouTube に載せてもいい？**

A. 載せること自体はできますが、YouTube はリアルに見える合成・加工コンテンツについて、投稿時の開示を求めています（[YouTube ヘルプ: 改変または合成されたコンテンツの開示](https://support.google.com/youtube/answer/14328491?hl=ja)）。収益化する場合は、使ったサービスの規約で商用利用が認められているかも確認してください。

## まとめ

- Sora は2026年4月に終了、Gemini の動画生成（Gemini Omni）は有料プランのみ。
- クラウドの無料枠は「数秒・透かし入り・商用不可」が基本。用途に合うサービスを見比べる用途に向いている。
- 無料で長く使いたい、透かしを入れたくないなら、Wan 2.2 などをローカルで動かす。GPU の VRAM は12GB以上が目安。
- 作った短いクリップは ffmpeg で1本につなげられる。
- 無料枠の条件はすぐ変わるので、使う前に公式の料金ページで確認する。
