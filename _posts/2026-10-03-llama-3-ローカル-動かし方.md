Meta AIが開発した最新LLM「Llama 3」を自分のPCやサーバー上で動かす方法をご紹介します。クラウドAPIを使わずに完全にローカルで動作させれば、コスト削減とプライバシー保護が実現できます。

## Ollamaを使用した最も簡単な方法

OllamaはMac/Windows/Linuxに対応し、設定が簡単です。

```bash
# Ollamaをインストール
curl -fsSL https://ollama.com/install.sh | sh

# Llama 3モデルをダウンロード
ollama pull llama3:8b
ollama run llama3:8b
```

これだけでチャットボットとして動作します。8Bパラメータはバランス型で、PC環境ならLlama-3.1-8Bがおすすめ。Mac M2/M4でも動作しますが、速度は制限されます。

## Dockerコンテナ方式での実行

Docker環境なら、他のモデルと切り替えやすいのがメリットです。

```bash
docker run -d --gpus=all -v /models:/models:z -p 11434-ollama/llama \
-e 'OLLAMA_MODELS=llama3:8b' ollama
```

この方法の利点は、モデルを外部ストレージからマウントできると、ダウンロード時間が短縮されることです。また、複数人のユーザーが共有して使うことも可能です。

## Python APIで直接呼び出す方法

より高度な制御が必要なら、Pythonから直接呼び出します。

```python
from ollama import Client
client = Client()
response = client.chat(model='llama3:8b', messages=[{'role':'user', 'content': 'こんにちは'}])
print(response['message'])
```

Hugging FaceのTransformersライブラリでも動作しますが、設定が複雑になります。ローカル環境での推論を高速に行いたい場合は、vLLMやTGIのような最適化されたライブラリを使うのが現実的です。

## GPUメモリ最適化と性能チューニング

Llama 3のローカル実行で最も重要なポイントはGPUメモリの確保です。8Bモデルは約14GBのVRAMを必要とし、16GB以上のGPUが推奨されます。

以下の方法でパフォーマンスを向上できます：
- `quantize`コマンドで精度を少し犠牲にしてモデルサイズを削減（q4_k quant化なら実質的に2倍高速）
- CPU推論モードに切り替えれば、GPUがない環境でも動作可能（ただし速度は大幅低下）
- Ollamaの `-m`オプションでメモリ使用量を制限し、OOMエラーを防ぐ

## ローカルLLM実行の注意点

- 初回ダウンロード時間は10〜30分かかることも
- 最新バージョンのOllama（0.4以上）が推奨
- WindowsではWSL2での動作が安定
- コストは電気代のみで、月額数百円程度
